# My 9 Maker

Make a "My 9" grid of books, albums, games, or films. Type a title and press Enter to find covers (Open Library for books, Apple Music for albums, Wikipedia for everything else), pick one of four styles, and save the grid as a PNG.

Everything runs in the browser. Your list is saved only in your own browser.

Live: https://williamhackspeare.github.io/my9/
